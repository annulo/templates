---
name: 写刷新内容的要点
description: 页面以前从 Google 带来点击、最近明显下滑：对比高峰和现在的数据、掉得最多的搜索词，读页面现在的内容，写出该更新、该补的地方，存成要点（谷歌排名页上确认后再交给助手改页面）
---

参数：`id` 是 content_decay 表里这个页面的记录。

## 1. 拿上下文

```bash
annulo run decay.context --input '{"id":"<id>"}'
```

输出里：`peak_*` 是高峰那 28 天（`peak_start` ~ `peak_end`）的点击、曝光、点击率、排名，不带前缀的是最近 28 天；`trend` 是最近 6 个 28 天的点击（从早到晚）；
`cause` 是按数据判断的原因（`rank` 排名掉了 / `ctr` 点击率降了 / `demand` 曝光少了）；`lost_queries` 是掉得最多的搜索词（高峰和现在的点击、排名）；`search_page_id` 是 search_pages 里同一个页面的记录。

`search_page_id` 是空的（最近 28 天这个页面没有曝光了）：告诉用户页面已经基本没有搜索流量，先确认页面还在、能打开，到「谷歌排名」同步一次后再来，不往下做。

再读页面现在的内容和站内相关页面：

```bash
annulo run gsc.pageContext --input '{"id":"<search_page_id>","related":true}'
```

`title`、`h1`、`headings`、`body`（正文开头）是线上现在的样子，`site_pages` 是站内相关页面（内链只能从这里选），`project` 是项目定位。
需要知道搜这些词的人现在看到什么，可以自己联网搜一下 `lost_queries` 里的词，看排在前面的是哪些页面、比我们多答了什么。

## 2. 写要点

这个页面以前排得上、有人点，现在少了。先判断为什么，再给改法：

- 排名掉了（`rank`）：多半是内容过时（年份、型号、价格口径、标准）、别家写得更全，或者搜索意图变了。对着 `lost_queries` 找页面没答好的地方；
- 点击率降了（`ctr`）：排名没怎么变，标题和描述不吸引人了，或者搜索结果页出了 AI 概览、别家的富结果。要点里写上标题描述怎么改，内容只补最缺的；
- 曝光少了（`demand`）：搜的人少了。看 `trend` 是不是每年这个时候都低（季节性），是的话 `summary` 里写清楚「可能是季节性，可以先不改」；不是的话按丢掉的搜索词补内容。

存的格式和「补内容」一样：

- `gaps`：页面现在过时、没答好、搜这些词的人想知道的问题，3~6 条，每条一句话，写明是哪个搜索词带出来的；
- `sections`：要更新或新增的小节，每节 `{ "heading": 小节标题, "what": 这一节改什么、补什么（一两句） }`，3~6 节；要更新的已有小节，标题照抄现在的；
- `faq`：值得在页面末尾加的常见问题，3~6 个，只写问题；
- `internal_links`：站内哪些页面应该加一个链接指向这个页面，每条 `{ "from": 页面 URL, "anchor": 锚文本 }`，`from` 只能从 `site_pages` 里选、原样照抄，没有相关的就给空数组；
- `summary`：一两句：为什么掉、最该改的是什么；点击率的原因要改标题描述的，把建议的新标题写在这里；
- 小标题、FAQ、锚文本的语言和页面现有语言一致；`gaps`、`summary`、`what` 给用户看，用界面语言写；
- 只基于页面已有的信息、项目资料和你搜到的公开信息提建议，不编造页面没有的事实（价格、数据、认证、案例），需要补事实的地方写成「补充 xxx（需要你提供）」。

## 3. 存

```bash
cat > /tmp/refresh.json <<'JSON'
{ "id": "<search_page_id>", "gaps": ["…"], "sections": [{ "heading": "…", "what": "…" }], "faq": ["…"], "internal_links": [{ "from": "…", "anchor": "…" }], "summary": "…" }
JSON
annulo run gsc.saveBrief --input @/tmp/refresh.json
```

注意 `id` 是 `search_page_id`，不是 content_decay 的 id。

存完回复用户：为什么掉、最该改的是什么（summary），请到「谷歌排名 → 流量下滑」里看要点，确认了点「交给助手改页面」。**这一步只存要点，不要去改站点代码。**
用户在这段对话里接着提意见，就照意见改要点，再存一次（覆盖上一份）。
