# 内容中心布局

列表将页头创建操作、文章/选题导航、搜索与状态筛选分开。默认内容行显示最多两行标题、一行摘要、渠道与更新时间，状态固定在右侧。紧凑模式将标题改为一行并收紧行距；摘要可单独隐藏。两项偏好保存到本浏览器，不修改业务数据。

详情使用单栏阅读布局，正文最大宽度760px，取消正文与操作栏并排。返回、状态、编辑/保存/取消与AI改写放在顶部吸附工具栏。文章、媒体版本和参考依据通过标签页切换。「更多」按钮紧邻「让AI改」，展开下拉操作菜单：改写要求、查看已发布页面（有链接时），分隔后为删除操作。菜单支持方向键、Escape与点击外部关闭。更新时间显示在标题下，完整时间可悬停查看；创建、更新与发布时间放在文章正文底部。关键词放在摘要后，默认两行，可展开。

标签页隐藏而不卸载对应编辑组件，切换时保留未保存的文章和渠道版本编辑。每篇文章使用独立组件key，防止状态串到其他文章。各渠道版本沿用现有审核和发布流程，切换标签不会保存、生成或发布内容。

正文预览保持沙箱iframe，并观察页面主题变化同步浅/深色。小窗口下工具栏可换行，列表渠道与时间始终放在标题下方，不依赖整窗宽度切换为窄侧栏。
