# 营销内容与 SEO 工作流

产品模板提供通用方法，具体品牌、三账号策略、内容、媒体与关键词以数据包进入用户项目，不写死在模板。

## 页面与数据

- 今日任务：最多三个优先动作，来自网站重要问题、到期复盘、未绑定账号、明确卡点及未核对发布声明。数据导入入口也在这里。统计卡片可点击：SEO 候选词进入增长计划的页面地图，内容版本计划与待绑定账号策略进入内容中心的营销计划（含账号绑定），到期复盘进入效果复盘。起步向导和产品资料仍可使用。
- 增长计划：SEO 页面地图按语言与唯一主页面归组近义词，保留历史来源、研究日期、人工相对难度及置信度；另一个标签继续使用原增长机会。页面汇总搜索数据不是单词数据，不能推算单词带来的订单。
- 网站内容与自媒体内容：选题、营销计划与成品按原 ID 合并为各自的内容流程，提供状态与目标筛选；信息不足的旧记录留待确认归属，不批量改写内容。账号定位与绑定在自媒体的「账号与定位」，灵感库在自媒体工作区。`marketing_plans` 与 `channel_strategies` 保留原表和关联；母内容继续复用 campaigns。具体兼容规则见 content-workspaces.md。
- 效果复盘：内容计划、选题、草稿、真实回执、完成复盘分别计数，不解释成用户转化漏斗。原 CSV 日数据仍是会话及事件次数，空值表示未采集。旧社媒互动不进入产品转化表。

## 导入

用 `marketing.importPack`，先 preview 后 apply。所有字段、关联产品、账号、平台、链接及参考库在写入前校验。自然查询键为产品/语言/市场/关键词，不能给同一个键分配不同主页面。计划以外部内容版本 ID 去重；媒体以 URL、执行稿以文件名去重。

运行时任务表的平台版本优先于 CSV 的规划快照；任务 completed 不能转换成 published。历史日期只保留，不自动创建排期。已存在的记录只报告变化并保留当前编辑，重试不覆盖资料。重复导入同一数据包不会重复建母题、计划、关键词或素材。写入失败后可再次提交已校验的同一包恢复，未声称跨表事务。

本机 run 请求上限为 1 MiB，页面将 JSON 数据包控制在 900 KB。更大的执行稿需分批导入，计划身份保持稳定。公开原始资料只作为数据，不授予工具执行权限；旧产品事实和效果表达使用前重新核对。

参考主页进入参考博主，具体笔记进入灵感来源，仍按 URL 去重。自己的任务媒体进入 assets；外部参考媒体继续作为灵感证据。`marketing.fillMaterials` 可补齐后到的正文和成品媒体：只填写空正文、追加未收录的媒体，保留现有顺序和标准草稿，重复调用不新增。支持 Annulo 官方上传返回的本机素材路径，并记录 material_snapshot 来源与读取时间。原始快照、来源与读取时间保留。

## 生产与账号

`marketing.prepareTopic` 幂等准备选题，携带母题、产品、策略、目标账号、CTA、UTM 和选中的执行稿。`marketing.sourceMaterial` 每次最多读取五份资料，避免把全部历史执行稿塞入上下文。编辑简报保留来源与账号元数据。

内容生成沿用 write-article，需求可通过 AI 要求修改；本机函数不交互调用模型。已有旧正文可确定性存为草稿，重复点击复用。选题与文章保留营销计划、账号和稳定版本标识。发布弹窗优先勾选可用的目标账号，仍由人确认。

同一平台可按账号策略和角度生成多个稳定 plan_key。相同 plan_key 重试不会覆盖原简报；无策略时沿用每平台一条的默认方式。账号名不是身份，未绑定策略不能假装已连接或已发布。

## 复盘

真实网站 publication、本机发布成功且有实际链接和时间的社媒帖子（source=shuttle），或用户核对的实际账号/链接/时间回执才生成 growth_reviews。历史平台采集记录不自动作新发布回执；同一账号、同一发布链接只生成一组检查点。社媒在 24h/72h/168h，网站在 168h/336h/672h 复盘；每六小时幂等整理一次，电脑关闭时不执行。修正回执时间后，未完成的旧检查点保留为 superseded，页面显示当前检查点。

复盘记录保留真实指标、观察时间、数据出处和下一步结论。空值不补零。当前版本自动安排复盘队列，指标取数复用已连接的搜索/社媒数据或报表导入；没有接入的经营数据不展示虚构漏斗。注册、创建项目、开始生成、生成成功属于激活主路径；编辑、发布、绑域名、结账、付费是并行结果。付费主体、订单与付费站点不能互换，日去重人数不能直接跨日相加。
