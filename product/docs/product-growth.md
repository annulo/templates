# 产品运营模板设计

独立模板 product；共用内容 UI 来自 core，网站能力来自按需组装的 core/features/websites，社媒来自 social 插件。trade 的源文件路径调整后，组装产物路径保持原样。公开产品模板通过 publish.py public 导出；没有新增 Annulo 原语。

七项起步：选择网站、确认产品与用户、连接渠道、搜索数据、增长目标、首个机会、首组内容。前两步与外贸助手共用网站选择和解析向导，资料确认后写入产品定位、功能和用户场景。无强制询盘接入或产品目录的外贸字段。SEO 方法参考 Danny 官方公开大纲，公开链接与执行边界在 product-seo skill。

增长机会按产品、语言、搜索意图、主词去重；验证状态需要证据、来源、时间。主题按产品和场景组织，平台计划生成选题并保留 campaign_id；网站 article、小红书/X post、抖音 video。生产任务幂等复用草稿，发布仍从内容中心操作。

转化第一版支持 CSV/JSON 日快照导入。键是 date/source/campaign_id；数据是会话与事件次数，未知值不计为零；没有用户级事件连接，不提供去重用户、用户留存或 cohort 漏斗。主题来源拆分必须互斥。GA4 关键事件独立展示，未自动等同于注册或激活。

第一版不会复制或修改真实产品网站、发布测试帖或填充假的增长数字。使用者连接自己的渠道后，按任务研究、生成、审核、发布与复盘。
