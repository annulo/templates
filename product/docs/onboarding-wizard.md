# 产品模板起步

新项目自动打开两步向导，与外贸助手共用网站选择、解析进度和过期结果保护：

1. 选择要运营的网站：输入官网网址，连接 Creght 后也能选择账号下的网站。仅读取所选网站；没有可用模型时进入手动填写。
2. 确认产品与用户：系统任务 product-onboarding 读取所选官网，整理定位、真实产品功能和用户场景。结果先保存为待确认草稿，用户可编辑，点击「开始运营」后写入 profile、products、use_cases。价格、案例、转化事件缺少证据时留空。

换网站或重新解析时保留已保存资料，确认前不覆盖。revision 阻止旧任务写回；重复确认按产品名称和关联场景复用记录。读取失败可重试或手填。向导可稍后再做，也可从总览或「产品与用户 → 从网站整理资料」重开。

总览共有七项起步：选择网站、确认产品与用户、连接渠道、搜索数据、增长目标、首个机会、首组内容。官网字段不会授予网站写入权限，营销发布仍需用户确认。

需要的转化事件在产品定位中定义，真实统计通过 CSV/JSON 导入。跳过搜索接入也可先生产内容。
