# 内容中心布局

列表将页头创建操作、文章/选题导航、搜索与筛选分开。筛选分两组：状态（草稿 / 已发布）和文章类型（长文 / 图文笔记 / 视频）。每行显示最多两行标题、一行摘要（图文笔记、视频显示正文开头）、类型标签与更新时间，状态固定在右侧，发出去的账号显示成标签，点了打开文章并定位到那条发布记录。

新建文章先选类型（三张卡片，写明字段和能发的平台），再写标题或主题；「AI 写文章」的弹窗里同样先选类型。

详情是单栏阅读布局，不再有标签页。顶部吸附工具栏：返回、类型、状态，右边是修改 / 保存、让 AI 改、改写、发布和「更多」（改文章的要求、删除）。正文区按类型显示：长文是沙箱 iframe 里的富文本，图文笔记是配图 + 纯文字，视频是播放器 + 简介。正文下面是「改写自 / 改写出的文章」，再下面是「发布记录」（每个账号一条：状态、时间、链接、互动、失败原因，失败的能重发，排期的能改时间或马上发，没发出去的能删记录）。

「发布」弹窗：列出所有社媒账号，支持这种类型、登录正常的能勾，别的灰掉并写明原因（不支持这种类型时给「改写」入口）；超出平台字数上限、发过一次的会提示。选「立即发布」或「定时发布」，逐条显示结果。

「改写」弹窗：选改成的类型，下面是这个类型的改写预设（点了填进要求，能改、能删），写好要求可以「存为预设」。
