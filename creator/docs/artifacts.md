## 概念

只有这几样东西，不多加层：

- **文章**：一层，按类型（长文 / 图文 / 视频）有自己的发布内容（下面统称**正文**：标题、正文或简介、配图或视频）。快速路径不变：选「图文」、写好、发小红书，全程一篇。
- **稿子**（`articles.draft`，富文本，可选）：每篇文章都能带一个，默认折叠。写「为什么写这篇」、大纲、草稿、剧本、分镜，从 Notion 导入的也可以放这里。**不发出去**：发布、平台字数检查都不看它。
- **产物**（artifacts）：AI 在一篇文章上做出来的**一组文件**（一条视频，或者小红书的 6 张图），就是资料库（`assets`）里的一条，带 `article_id`、`chat_id`、`note`（备注）。
- **引用**：`@表:id#n`，指页面上任何一样东西，贴进对话里交给 AI。

## 稿子

文章页标题下面一条「稿子」的展开条（有内容时显示第一行），展开后是编辑框，下面三个入口：

- **放进正文**：不经过 AI，按这篇的类型转格式放进正文（长文保留富文本，图文、视频转纯文字、图片抽出来；`core/local/convert.ts`）。正文不是空的先问「替换现在的正文？」。
- **AI 写成正文**：模板自带的「在这篇上做」预设「照稿子写正文」（所有类型都有，Prompt 用户能改），照用户的写作要求写这篇的正文。正文不是空的先问一句。
- **改写成…**：列「另写一篇」的预设，另存一篇别的类型。

给 AI 的规则（任务、ANNULO.md、系统里各写一次）：**只说明稿子是什么，不规定先读哪个**。上下文里稿子和正文都给，读哪个、怎么用由 AI 自己定；「另写一篇」只生成新文章的正文，新文章的稿子空着（不复制，`source_id` 指回原文）；用户没让写稿子就不改稿子。

稿子和做出来的视频、笔记在同一篇里，不用列表分组；一份稿子要出几种内容时用「另写一篇」，新文章顶上「改写自 …」、原文下面「改写出的文章」（已有）。

## 交给 AI：两种做法，按文章类型给预设

文章页只有一个「交给 AI」，点开先列预设，最下面能自己写一句。预设 = 名字 + **做法** + 适用的文章类型 + Prompt（用户能改能加，模板自带几条，见 `core/lib/presets.ts`）：

| 做法 | 做什么 | 例子（模板自带） |
|---|---|---|
| **在这篇上做** | 写这篇的正文、做产物（挂在这篇上），或者两样一起，不新建文章 | 所有类型：「照稿子写正文」；图文：「配 5 张图」「做封面」；视频：「做视频」；长文：「配图」「做封面」 |
| **另写一篇** | 就是现在的改写：另存一篇新文章（`source_id` 指回这篇），在列表里缩在原文下面 | 「改写成小红书笔记」「扩成长文」「做成视频」（另写一篇视频，接着在新的那篇上做视频） |

- 按钮不再写死「做视频」：做图文就是「交给 AI → 配 5 张图」。
- 「在这篇上做」背后一个通用任务（现在的 `make-video` 改出来，`tasks/work-on-article.md`）：给它这篇的稿子、正文、产物（有原文连原文），照 Prompt 做；要写正文调 `content.update`，要出文件 `annulo upload --local` 再 `assets.add`。做什么由 Prompt 定，任务里不分视频、图片。
- 「另写一篇」还是 `rewrite-article`：上下文里给原文的稿子和正文，只生成新文章的正文。
- 要改就回到做它的那段对话（「继续对话」），不弹框、不新开对话。

## 产物：一组文件

- 资料库表加 `files`：`[{ url, mime, name }]`，顺序就是轮播顺序，第一个是封面。只有一个文件时可以只用 `url`（老数据不用改）。备注、`chat_id`、`article_id` 挂在这一条上，一组共用。
- `assets.add({ urls: [...] | url, article_id, note, use? })` 一次存一组；`mime` 按扩展名推。筛选按里面的文件：全是图片归「图片」，全是视频归「视频」，混着的归「其他」。
- **整组重做存一个新的；只改其中一个改原来那组**：`assets.replace({ asset_id, n, url, note })` 换掉第 n 个文件、在备注后面追加这次改了什么；这篇文章里用着旧地址的地方（图文的 `images`、视频的 `video`）一起换成新的。已经发出去的帖子不动（发布记录里是当时的）。换下来的旧文件没人引用了，Annulo 过 90 天清掉。
- 「用这个」按文章类型：视频「发布用这个」（取组里的视频）；图文「用作配图」（这一组按顺序换成这篇的配图，之后在编辑框里还能删、调顺序）；长文「插入正文」或「设为封面」。
- 文章页的产物列表：一组显示成一排缩略图（多的写「+3」），点开左右翻；下面「打开 / 在访达中显示」（当前这张）；备注、按钮。能整组删、也能删其中一张。
- 资料库：一组是一张卡片（封面 + 「6 张」），点开翻看；「从资料库选图」里一组能整组选，也能展开挑几张。

## 引用

- 列表每一行（文章、选题、资料）的「⋯」里「复制引用」；产物卡片、资料库卡片上「复制引用」；看大图时每一张都能单独复制（带 `#n`）。文章列表能勾选多篇一起复制（一行一个），比如交给 AI 做总结。
- `#n` 是这条记录文件列表里的第 n 个（从 1 开始）：资料库是 `files`（只有 `url` 时 `#1` 就是它），图文文章是 `images`。模板在表声明里写 `"files_field"`，ANNULO.md 里也写清楚。
- 贴进对话后 Annulo 显示成标签、把解析结果交给助手（Annulo 的 `docs/references.md`）。
