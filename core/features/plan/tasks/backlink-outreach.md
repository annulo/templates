name: 写外链申请材料
description: 给一条外链机会写用户拿去就能用的东西：目录、B2B 平台、选品库写要填的公司介绍和字段；客户、合作方、媒体、品牌被提到没链接的写邀请邮件。只写不发，存在这条外链上，用户在对话里接着改

参数：`id` 是外链表（backlinks）里的一条。

## 1. 拿上下文

```bash
annulo run backlinks.outreachContext --input '{"id":"<id>"}'
```

- `link`：这条外链：类型 `kind`、网站 `platform`、`source_url`、要指向我们哪一页 `target_url`、为什么做 `reason`、怎么申请 `how_to`；
- `previous`：上次写的版本（有的话在它基础上改，别从头另起）；
- `project`、`company`、`products`：我们的资料。项目里有知识库时（`annulo run knowledge.search --input '{"q":"<关键词>"}'`）查成立年份、工厂、认证、出口国家、案例这些具体事实。

打开 `source_url`（`curl -sL <网址>` 或你的网页工具）看对方：申请页要填哪些字段、有没有字数限制和分类；要发邮件的找联系方式（Contact、Advertise / Write for us、编辑或负责人名字）、对方写过什么、和我们哪里对得上。

## 2. 写

按 `kind` 和对方是谁，写下面一种（用对方网站的语言，多半是英文）：

- **要填表的**（directory 行业目录、展会名录、选品库，b2b 平台公司页）：照申请页的字段一项一项写好：公司名、一句话介绍、长介绍（按字数限制）、分类怎么选、产品关键词、网址填哪个（`target_url`）、要上传什么（logo、产品图、认证），用户照着复制粘贴；
- **要发邮件的**（客户和合作方的署名、上游材料品牌、媒体和客座文章、品牌被提到没链接）：一封邮件：主题、正文。开头说清我们是谁、和对方什么关系（合作过的项目、用了对方的材料、对方哪篇文章提到了我们），中间说请对方做什么（在哪一页加一个指向 `target_url` 的链接、或者投哪个题目），给对方的好处，结尾一句话。不知道收件人名字就写 `[名字]` 让用户填；
- 两种都需要的（先填表、再发邮件催审核），两样都写。

写在最上面一行：发给谁、在哪里填或发（申请页地址、邮箱）。

怎么写（长短、语气、要不要附带什么）照这件任务的写法：用户改过的在 `user/prompts/backlink-outreach.md`，没改过用模板默认的 `prompts/backlink-outreach.md`（开任务时会告诉你用哪份；用户在对话里让你改写法，就把改后的完整写法存到 `user/prompts/backlink-outreach.md`）。写法和下面的规则冲突时，以规则为准。

## 3. 存

```bash
cat > /tmp/outreach.json <<'JSON'
{ "id": "<id>", "text": "<Markdown 全文>" }
JSON
annulo run backlinks.saveOutreach --input @/tmp/outreach.json
```

存完回复用户：写好了什么（一句话），去「SEO 与关键词 → 外链」这一条下面展开「申请材料」复制；发出去或提交了就点「已申请」。

用户在这段对话里提意见（短一点、换个语气、加上某个项目），改完**整篇重新存一次**（覆盖成新版），再告诉用户改了哪里。

## 规则

- **只写不发**：不替用户注册、提交表单、发邮件；
- **不编事实**：年份、规模、认证、客户、项目只写资料和知识库里有的，没有的不写或写成 `[待补：…]` 让用户填；不编和对方的关系（没合作过就不说合作过）；
- 不写付费买链接、交换链接的提议；
- 回复用户用界面语言，申请材料和邮件用对方网站的语言。
