# 自媒体内容：左列表、右编辑

外贸和产品运营的「自媒体内容」页（2026-11-20 重做）。设计图在 `~/dev/shuttle/outputs/social-workspace/`。

## 布局（`components/views/SocialWorkspace.tsx`）

- 左：草稿 / 排期 / 已发布（有归档的再多一个「已归档」）四个页签（按内容阶段 `ContentStage` 分），搜索、账号筛选，「新建内容」下拉，列表行是正文前两句 + 账号图标 + 状态 + 时间（已发布的行显示阅读数）。
  左下是出选题、导入营销资料的小入口；待确认归属、平台直接发的、待复盘在列表上方给文字入口，点了回到原来的整页。
- 右：点哪条就在原地显示。**草稿**（图文、视频）是新的编辑器；**排期、已发布**（和长文）是原来的文章页（发布记录、数据、复盘），由 `ContentWorkspace` 的 `renderArticle` 传进来。
- 选题、计划、平台直接发的帖子、新建 AI 向导仍是原来的整页（`ContentWorkspace` 里 `split` 为 false 时）。

## 新建（2026-11-20 重做）

- 左上是分体按钮：左半「＋ 新建内容」直接用**上次新建用的账号**（筛选了账号就用它，没有就取第一个能用的）新建空白草稿，右边马上能写；右半 ⌄ 展开菜单。
- 菜单：每个账号一行（点哪个就用哪个新建）、「选择多个账号…」（弹窗勾选，第一个是主账号）；「复用已发布的内容」（选一条已发出去的，`convert.copy` 复制成新草稿）；设置里「添加或管理账号」跳渠道页。没有「默认账号」设置。
- 「让 AI 做」（三步向导 `SocialCreate`）和「录入已有内容」的入口从这里去掉了（组件和 `?create=` 路由还在，选题行点开仍能进向导）。

## 编辑器

- 正文、标题（可不写，存的时候取正文第一句）、话题，停手 0.8 秒自动存进 `articles`。
- **图片、视频是一个有序列表（`articles.media`：`[{ kind, url, cover? }]`），可以多个、混放、拖动排序，上传不覆盖**（2026-11-20）。`images`、`video`、`video_cover` 是从它算出来给插件用的（图片、第一个视频和它的封面）。X 一条最多 4 个图片和视频、能混放（插件 `_fields.ts` 的 `media`，帖子存 `social_posts.media`）；别的平台一条只收一个视频、图和视频不能同发，所以右栏检查和 `publish.prepare` 按平台报「最多 n 个图片和视频」「一条只能发 1 个视频」「图片和视频不能同发」，不悄悄丢。视频的封面在视频上点「设封面」。
- **直接粘贴或拖进来图片、视频**（整个编辑区接，`usePasteFiles` 带视频）：有视频就是视频帖（`type=video`，视频走 `uploadLocalFile`，存成本机文件，发布时由这台电脑传给平台），
  只有图片是图文（`type=post`，图片进素材库）；
- 右栏：发布前检查（已连账号各平台的字数、图数上限，来自 `plugins/social/local/_fields.ts`）、预览。默认收起，大屏上点工具栏的按钮浮在编辑区右边、不占宽度（开没开记在 localStorage `social_ws.side`）；有检查问题时按钮上一个橙点。
- 发布 / 排期：原来的 `PublishDialog`（选账号、立即或定时、逐个账号的问题），发之前先把没存的存掉。
- 让 AI 改：`tasks/revise-article.md`，和文章页的「AI 修改」是同一个任务；AI 改完表里变了，这边没动过就换成新的。

## 发到哪些账号、各账号的文字（2026-11-20）

- `articles.targets`：要发的账号 id（JSON 数组），顺序就是编辑器顶部页签的顺序，**第一个是主账号**；主文案就是文章自己的 `title`、`body`、`tags`（老数据、AI 改写、列表都不用动）。没有 `targets` 的老文章读 `target_account_id`。
- `articles.variants`：某个账号单独改过的文字 `{ <账号 id>: { body, tags } }`。没有这个账号的 key 就是**跟随主文案**；非主账号页签上的开关关掉就是把主文案复制一份进 `variants`，打开就删掉它（改过的先确认）。
- 图片、视频默认所有账号共用；非主账号可以打开「图片和视频也单独设置」，就把主账号现在的图片、视频复制一份进 `variants[账号].media`（`{ images, video, video_cover }`），之后在这页单独粘贴、删除、排序；有视频就是视频帖，否则图文，各账号形式可以不同。关掉就丢掉自己的、改回共用（不一样时先确认）。换主账号：新主账号有自己的版本，它的文字成为主文案，原来的主文案留给原主账号当单独版本。
- 新建「自己写」先弹窗选账号（默认：筛选的账号 → 最近一条用的账号 → 第一个能用的账号）；编辑页顶部「＋ 账号」随时改。
- 发布：`local/publish.ts` 的 `prepare` 在生成每个账号的帖子前把 `variants[账号]`（文字、媒体、形式）叠在文章上（`withVariant`），平台收不收也按这个账号那一版的形式查；发布弹窗默认勾 `targets`。「文章本身就是要发的内容」不变：帖子仍是发布记录，已发出去的不受之后修改影响。
- 「让 AI 改这条」只改主文案，不碰 `variants`。

## 平台上直接发的帖子、没有归属的内容（2026-11-20）

- 「待复盘」「在平台上发的」「待确认归属」三个页签去掉了。
- **平台上直接发的帖子**（采集时发现、不属于任何内容）放进「已发布」，行上标「平台上发的」；「已发布」上方按来源筛：全部 / 从 Annulo 发的 / 平台上发的。点开右边是只读的 `PlatformPostView`（和已发布内容同一个 `SentContent`），不用先并入：
  「复用」复制成一条新草稿（`content-workspace.reusePost`，发到原来的账号，不关联原帖子）；「让 AI 照这条再写一条」复制后交给 `revise-article` 重写；「并入内容」在「更多」里（`?adopt=<帖子 id>` 打开原来的 `AdoptPostDialog`）。
- 采集时社媒插件先按 id、再按文字和时间把平台帖子对回 Annulo 发出去、没记上 id 的那条（`plugins/social/local/_snapshot.ts` 的 `matchUnlinked`：文字一样，或相似度 ≥ 0.85 且发布时间相差 3 天内；显示失败、卡在发布中其实发出去的也认），对上就不再算「平台上发的」。X、Instagram、Threads、LinkedIn、Facebook 用它。
- **没有归属的内容**不单独一栏：放在列表里（自媒体在「草稿」），行上一个「选发到哪」，点开是原来的确认归属。源头上 `topics.save` 必须带 `workspace`（geo、competitor 来源自动是 website）；读的时候来源是 search / keyword / geo / competitor 的、记了搜索关键词的选题归网站（`lib/contentWorkspace.ts` 的 `recordWorkspaces`）。


## 已发布 Facebook 原帖管理（2026-11-27）

官方 API 连接的 Facebook 公共主页，在 `SentContent`、文章发布记录和社媒帖子预览共用 `FacebookPostActions`：编辑正文与话题调 `social/social.edit`，独立编辑弹窗不自动保存，点击「保存到 Facebook」才执行。原文章、图片、发布时间与互动数据保留。Facebook 仅允许应用编辑同应用创建的帖子，弹窗中说明此限制。

已发布内容页和数据页的删除先核对账号、正文，再确认 `social/social.remove`。等待期间不允许重复操作或关闭弹窗；失败显示原因并保留输入，成功刷新记录。已发布预览不再提供只修改本机记录的草稿编辑入口。模板最低 social 版本为 0.16.0，无需 Annulo 新原语。


账号数据页和账号概览的帖子列表统一点击标题打开预览弹窗，不再因 `article_id` 是否存在而直接跳走。预览底部的「前往已发布（Posted）」快捷按钮才进入自媒体内容，定位对应文章及发布记录；文章已不存在的退回已发布列表。从链接进入已发布列表时直接选中 Posted 页签。
