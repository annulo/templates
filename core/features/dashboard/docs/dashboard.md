# 运营总览的数据看板

参考 TradeMax 的网站数据看板（2026-10-16）：总览最上面从「待办」改成「数据」。

- 取数：`local/dashboard.ts` 的 `summary({ days, channel_id? })` 一次算好，页面只调一次。每个来源单独取、单独容错：没连上标 `status=none`（卡片写「去连接」，不显示 0），出错标 `error`。
- 网站访客：Creght 站点用平台访问统计这段时间的**去重**访客（每天的加起来会重复算人），WordPress 用 GA4 的用户数。平台最多给最近 31 天的按天数据，上期只有按天数据覆盖了整个上期才比，不然 `prev=null`。
- 谷歌点击：`search_daily` 按天加。AI 搜索可见度：每个网站最近一次检测的分数（几个网站取平均）和它的上一次比。
- 询盘、漏斗：`leads` 里的真实询盘；漏斗只看这段时间进来的询盘走到了哪一步。推进中的商机是现在处在已联系 / 已报价 / 谈判中的，不和上期比。
- 社媒互动：`social_daily` 存的是累计数，按账号算每天比前一条多了多少（`socialDeltas`）。
- 页面：`components/Dashboard.tsx`，图用 core 的 `TrendChart`；访客和询盘量级差太多，趋势图切换着看一个指标。第 150 版起总览只放看板（和起步清单），原来的今日工作、周报、账号表、更多运营数据都去掉了。
